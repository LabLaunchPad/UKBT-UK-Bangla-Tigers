# Few-shot: a bad decision

## Question
Can we use Adelux demo player information?

## Bad answer
> "Yes, because it is part of the template."

## Why invalid
Template provenance != UKBT factual provenance. The template's demo content
describes a fictional padel club. Publishing it as UKBT information would create
an invented organization fact, regardless of the template's licence.

## Correct answer
`UNKNOWN` / NOT PERMITTED AS UKBT FACT. Use only verified UKBT player
information. If none exists, the page is designed so the unknown stays explicit.
