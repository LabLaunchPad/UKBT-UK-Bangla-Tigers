# Visual Verification Contract

For UI work, capture:
- route
- viewport width/height
- device scale if relevant
- browser/version
- git SHA
- asset hashes where relevant
- screenshot
- key DOM selectors
- computed style measurements for important elements

Check desktop + mobile, normal + important interaction states, and content extremes where relevant.

Visual acceptance is not "looks nicer". It is measurable preservation or approved change of structure, hierarchy, spacing, typography, assets, interaction, responsiveness, accessibility and brand grammar.
