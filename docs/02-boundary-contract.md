# DesignOS × UKBT Boundary Contract

DesignOS is an agentic engineering framework; UKBT is a domain-specific content-first site. Do not force architectural symmetry.

UKBT may reuse patterns such as:
- deterministic-first reasoning
- evidence records
- bounded tool output
- progressive disclosure
- permission discipline

UKBT must not blindly import:
- DesignOS vision routing
- DesignOS template-admission implementation
- DesignOS domain classification as its content model
- DesignOS agent topology merely to match it
