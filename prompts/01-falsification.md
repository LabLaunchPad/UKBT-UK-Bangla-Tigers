# PROMPT 01 — FALSIFY THE BASELINE

Act as an independent verifier.

Attempt to falsify at least these classes:
- stack/version claims;
- current scripts;
- truth publication boundary;
- test/release claims;
- fixture/result blocker;
- visual foundation/license status;
- agent permissions;
- route count;
- SEO/a11y status;
- deployment assumptions;
- dependency/lockfile state.

Do not fix anything.

For every claim: CLAIM → SOURCE → TEST → RESULT → CLASSIFICATION.

At least one deliberate counterexample must be attempted.
Write `artifacts/admission/falsification.md`.
