# PROMPT 19 — SCALE TO THE REST OF THE SITE (Stage 9)

Run only once the homepage has passed independent verification.

Derive the remaining page architecture from the same verified design system. Do
NOT duplicate the homepage manually.

First create a route/content matrix:

| ROUTE | PURPOSE | DATA REQUIRED | TRUTH SOURCE REQUIRED | SEO REQUIREMENTS | COMPONENTS | STATUS |
|---|---|---|---|---|---|---|

Identify which pages can be generated from shared components/data.

**Do not implement pages whose required organization-specific evidence does not
exist.** They stay in the matrix with `STATUS = BLOCKED_ON_EVIDENCE`. A page
that cannot be sourced is not a page that gets plausible filler.

Priority order: 1. shared shell/navigation; 2. content infrastructure; 3. team/club
information; 4. players; 5. leadership; 6. fixtures/results; 7. other pages.

For each page: **PLAN → IMPLEMENT → VERIFY → RECEIPT.**

Never implement all pages first and verify later.
