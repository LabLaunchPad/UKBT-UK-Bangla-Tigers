# PROMPT 02 — FREEZE THE CURRENT CONTRACT

Using only verified baseline evidence, create a machine-checkable task/repository contract.

Freeze:
- repository identity;
- current branch/SHA;
- runtime fingerprint;
- package/lockfile identity;
- truth/provenance contract;
- route contract;
- design-token/component contract;
- SEO/a11y/release gates;
- agent permissions;
- allowed side effects;
- unresolved blockers;
- known unknowns.

Do not implement.

If the repository has an existing contract, reconcile it rather than duplicating it. Never create a second competing source of truth.
