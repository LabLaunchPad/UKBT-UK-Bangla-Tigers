# PROMPT 04 — CONTROLLED IMPLEMENTATION

Implement only the approved contract.

Rules:
- one writer at a time;
- no unrelated cleanup;
- no silent dependency changes;
- no source-of-truth duplication;
- no weakening tests/gates;
- no invented content;
- no credentials in files/logs;
- stop on scope expansion;
- stop on contract conflict;
- stop on unexpected destructive behavior.

Use the smallest change that satisfies acceptance criteria.

After edits, run narrow deterministic checks first. Produce an implementation receipt with exact commands and exit codes.
