# PROMPT 07 — ADAPTIVE LEARNING WITHOUT OVERFITTING

Extract candidate learnings only from observed execution.

For each:
OBSERVATION → OUTCOME → CAUSAL HYPOTHESIS → COUNTEREXAMPLE → GENERAL RULE → VERIFICATION → STATUS.

A learning must be narrower than the evidence supports; do not turn one repository quirk into a universal rule.

Before marking VERIFIED, replay it against at least one adversarial case from `adversarial/`.

Do not store model personality preferences as engineering doctrine.
