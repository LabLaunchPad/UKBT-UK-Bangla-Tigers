# PROMPT 17 — HOMEPAGE (Stage 7)

Implement the UK Bangla Tigers homepage using: 1. `contracts/REPOSITORY-CONTRACT.md`;
2. `artifacts/ui/DESIGN-SYSTEM.md`; 3. `artifacts/ui/REFERENCE-ANALYSIS.md`.

The homepage must be built from reusable components, not bespoke markup.

**Before implementation** create `artifacts/pages/HOMEPAGE-CONTRACT.md` defining:
sections · content requirements · data requirements · responsive behavior ·
accessibility requirements · SEO requirements · acceptance criteria.

Do not invent organization-specific facts. Where real data is unavailable, use
clearly marked non-publishable placeholders that the truth gate rejects.

Implement only the homepage.

Then verify: desktop · tablet · mobile · keyboard navigation · focus states ·
semantic structure · heading hierarchy · image alt behavior · contrast ·
metadata · structured data where applicable · build · tests.

Capture before/after screenshots **and** deterministic UI measurements
(`docs/07-visual-contract.md`: DOM/CSS/computed styles first, screenshots
second, taste last).

Create `artifacts/receipts/HOMEPAGE.md`.

Do not proceed to other pages until the homepage passes independent verification.
